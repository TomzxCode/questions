# Questions

This directory stores questions and their answers as individual markdown files.

## Workflow

When a question is asked in this directory:

1. Create a new markdown file named after the question topic. Use a short, descriptive, kebab-case name (e.g. `how-to-configure-logging.md`). If a file covering the same topic already exists, reuse it instead of creating a new one.
2. The file must contain:
   - A top-level heading with the question.
   - A `## Answer` section with the answer.
3. If a follow-up question is asked within the same session, update the existing file:
   - Add the follow-up as a new `## Follow-up: <short summary>` section (or append to an existing follow-up section on the same topic).
   - Record both the follow-up question and its answer.
   - Keep earlier content intact; only append or refine.

## Naming convention

- One file per question topic.
- Lowercase, kebab-case, `.md` extension.
- Pick a name that reflects the core subject of the question, not the date or session.
